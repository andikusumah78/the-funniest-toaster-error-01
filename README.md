The funniest error message a kitchen toaster would show its owner: one deadpan line, at most 120 characters. `main.py` (pure stdlib, no network, no clock) writes it to `/output/entry.txt` and verifies the write by reading it back, so every run produces byte-identical output.

## Run it

```sh
python3 main.py
```
